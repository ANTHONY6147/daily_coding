## Key Takeaways

1. A reference is another name for an existing variable.
2. References are commonly used for pass-by-reference.
3. Pointers store memory addresses.
4. nullptr represents a pointer that is not currently pointing to an object.
5. new dynamically allocates memory.
6. delete releases dynamically allocated single objects.
7. delete[] releases dynamically allocated arrays.
8. Dynamically allocated memory should be properly released.
