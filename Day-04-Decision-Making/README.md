## Key Takeaways

- The `if` statement executes code only when a condition is true.
- The `if-else` statement handles both true and false conditions.
- The `else-if` ladder checks multiple conditions.
- Nested `if` allows one decision inside another.
- `switch` is useful when choosing between multiple fixed options.
